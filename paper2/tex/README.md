# paper2/tex: LaTeX manuscript for paper 2

Two builds come from the same sources:

| Build | File | Mode |
|---|---|---|
| TMLR double-blind submission | `anonymous.pdf` | `\usepackage{tmlr}` |
| arXiv preprint | `preprint.pdf` | `\usepackage[preprint]{tmlr}` |

Run `make` (both PDFs), `make check` (author-name and repository-owner search in text and metadata) or `make clean`.

## Sources

- **Main text:** `paper2/draft/paper2_draft.md`, the frozen source text. It was exported on 2026-10-04 from the Claude Docs draft
  "Paper 2 — Runaway edges in KANs (draft)", and is now at revision 55 (42,733 bytes, the same size as the Docs export of
  2026-10-25; number check against the claims table, revision 37, before the build).
  - `build_tex.py` converts it faithfully into `body.tex`.
  - No claim is rewritten. Formulas become LaTeX math, the draft's author-year citations become `natbib` commands, and its
    tables become `booktabs` tables.
- **Figures:** `paper2/figures/*.pdf`. Captions are drafted from each figure's sidecar JSON, quote only numbers present there,
  and are marked `% CAPTION-DRAFT: review`.
- **Appendices A–E:** generated by `build_tex.py`.
  - **A:** from the committed verdict sections (`paper2/synth_prereg.md`, `electrolyte_case_study_summary.md`,
    `arch/sc_prereg.md`, `arch/ex_prereg.md`, and the revision studies `paper2/revision/freeze_prereg.md`, `infimum_prereg.md`
    (Phases 1–2 and the control arm), `dose_prereg.md`, `bspline_prereg.md` (Step 1 and the post-hoc checks 1–2)). Each study
    opens with its pre-registration's title and its committed question or theory paragraph; prediction wording comes from the
    committed prediction bullets or verdict tables; study names are readable names, not file names.
  - **B:** from the post-hoc files and their commit subjects, each labelled as recorded in its files (post hoc; post hoc with
    rules, outcomes or predictions fixed in advance; post-outcome diagnostic; the applicability analysis as descriptive with its
    plan committed first).
  - **C:** from `paper2/figures/MANIFEST.md`.
  - **D:** protocol prose, marked `% DRAFT-TEXT: review`, plus a pre-registration, amendment and crash-record table generated
    from git, and a table of every change made after an outcome was known, quoted from the committed files with the date and
    commit of the quoted text (the five B-spline calibration-step amendments, the dose study's correlation tolerance, the added
    stop reasons, the X6 and Z2 readings that did not fit, and the dropped predictive follow-up).
  - **E:** the supplementary figures S1–S3.
  - Do not edit the generated `.tex` files by hand; rerun `python3 paper2/tex/build_tex.py` from the repo root.

## Conversion rules (draft text -> LaTeX)

- **Model name:** the draft source keeps "KAN-delta"; the LaTeX conversion renders it as KAN-$\delta$. This covers
  SC-KAN-delta and every appendix table, and matches the figure graphics, which say KAN-δ.
- **Powers of ten:** "1e-5" style numbers become $10^{-5}$, and "7e-10" becomes $7\times10^{-10}$. Identifiers and file
  names, such as `close_1e-06`, are left unchanged.
- **Unicode:** formulas and Greek letters become LaTeX math. The draft's author-year citations become `natbib` commands.

## Python (pinned)

All Python in this repository's paper pipeline runs under one pinned interpreter, `/usr/bin/python3`. That is the system
Python 3.9.6, which produced every committed result.

- **Libraries:** numpy 1.26.4, matplotlib 3.9.4, torch 2.8.0, scipy 1.13.1, pandas 2.3.3.
- **In the Makefile:** set as `PYTHON := /usr/bin/python3`. It is used by:
  - the generated sources (`build_tex.py`);
  - `make figures` (the scripts in `paper2/figures/`);
  - `make review` (`gen_review_items.py`);
  - `make submission` (`check_submission.py`).
- **Avoid `python3` from PATH:** on this machine it resolves to Homebrew's Python, which came in with poppler and has no
  matplotlib. The shell PATH is unchanged and nothing was uninstalled.

## Submission package

`make submission` assembles `submission_tmlr/`, which is git-ignored, with exactly what goes to TMLR:

- **Now:** `anonymous.pdf`.
- **Later:** an anonymised code archive (`code_anonymised.zip`), not built yet.

It then runs `check_submission.py`, which fails if the folder holds:
- any file other than those allowed;
- `commitmap.json` or the preprint;
- any file whose text, metadata or decompressed PDF streams contain the author's name, the repository owner, name or
  URL, "Berlin", "ORCID", any commit hash of this repository, or any real repository file name from `commitmap.json`.

A negative test, the preprint copied in as `anonymous.pdf`, fails with 119 findings.

## Anonymity

The anonymous build has:
- no author block (`\author{}`; TMLR prints "Anonymous authors");
- no affiliation, ORCID or acknowledgments;
- an empty `pdfauthor`;
- "Code will be released upon publication." in place of the repository URL.

The preprint build adds the author, affiliation, an ORCID placeholder (`% ORCID-PLACEHOLDER`) and the public repository URL.

## Anonymous build: what is replaced

- **Commit hashes:** all 87 commit hashes in the appendices are replaced by `S-01` … `S-87`, in chronological order.
- **File and archive names:** all 61 distinct repository file and archive names are replaced by `F-NN` and `W-NN`, in order of
  first appearance.
- **Figure IDs:** the figure IDs in Appendix C (`\figname`) are omitted.
- **Mapping:** `commitmap.json` holds the full label-to-original mapping. It is not part of either PDF. It identifies the
  repository, so it must not be shared with the submission.
- **Preprint:** the preprint build keeps every real hash and name.
